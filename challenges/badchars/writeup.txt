the challenge tells us that 'x', 'g', '.', 'a' are badchars
and we cannot use them as inputs in our ROP chain

we need to find bytes x such that x ^ key = b"flag.txt", and x, key dont contain any badchars
then we store x in .data, and xor it against key via the ROP chain

and finally call print_file(rdi), rdi -> .data;

to find ROP gadgets with badchars filtering i use:
    ROPgadget --binary ./badchars --badbytes "78|67|61|2e"

using ROPgadget i find useful:
1.    0x400628: xor byte ptr [r15], r14b ; ret
2.    0x4006a0: pop r14; pop r15; ret
3.    0x4004ee: ret ; in case i need to align rsp
4.    0x400634: mov qword ptr [r13], r12 ; ret
5.    0x40069c: pop r12; pop r13; pop r14; pop r15; ret

I will use 5 to load my values into r12, r13
and then load the x buffer to .data via 4
and then xor it against key using 1 and 2

then i will load the .data pointer into rdi with: 0x4006a3: pop rdi; ret
and ret2print_file
